# Security

HostLens is under development. No stable release or long-term support policy has been published; security fixes target the current development version.

Report suspected vulnerabilities privately to the repository owner. Use GitHub private vulnerability reporting if available. Do not put credentials, sensitive host output, or exploit details in public issues.

Include the affected commit, deployment mode, minimal reproduction, expected protection, and observed result. Use synthetic data and identify whether the issue requires local administrator access.

Review the [security model](docs/v1/SPEC.md#components-and-trust), [operator guidance](docs/v1/OPERATIONS.md), and [validation limits](docs/v1/VALIDATION.md) before deployment. Checksums detect corruption; obtain binaries and checksums through a trusted channel.
