# Adopt Apache-2.0

## Why

The owner selected Apache-2.0 to permit commercial redistribution while preserving applicable HostLens attribution. The repository and local archives currently leave the project license undecided.

## What Changes

- **License:** Add the official Apache-2.0 text and a HostLens attribution notice identifying Monska85 and the original repository.
- **Archives:** Include the project license and notice alongside existing dependency notices and cover them with archive checksums.
- **Documentation:** Record the selected license while keeping signing and publication deferred.

## Capabilities

### New Capabilities

None.

### Modified Capabilities

- **installation-lifecycle:** Require project licensing and attribution material in distributed archives.

## Impact

License files, archive packaging, and operator/specification documentation change. Runtime behavior and dependency versions stay unchanged. No commit, remote publication, or release signing is authorized.
